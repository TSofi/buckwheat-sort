# Roadmap

Buckwheat Sort is the first game of a small portal of calm, repetitive mini games: something to do with your
hands instead of scrolling social media. Hours are rough estimates.

## 1. Code structure and tests (~6 h)
- [ ] Move the game logic out of `buckwheat.html` into its own JavaScript module (grains, scoring, levels).
- [ ] Unit tests for scoring, level progression and the timer.
- [ ] Lint and format checks.

## 2. Game portal (~6 h)
- [ ] Start page with a list of games; Buckwheat Sort is the first one.
- [ ] Shared code for all games: profile, language, sound, saving progress.
- [ ] Add more calm "do something simple" games (ideas still open).

## 3. Accounts (~6 h)
- [ ] Keep guest mode: play without an account.
- [ ] Optional account, so progress is not tied to one browser.
- [ ] Connect with friends and see each other's progress.

## 4. Buckwheat Sort gameplay (~4 h)
- [ ] Difficulty modes, with new kinds of bad grains and debris in the harder ones.
- [ ] Wind: from time to time it mixes the grains on the table.
- [ ] Streak: a bonus for a series of correct sorts in a row.

## 5. Progress (~3 h)
- [ ] Stats screen: games played, accuracy, best level over time.
- [ ] Export and import progress.
